# Rules for the stack (docker/, seed/, .env.example)

- Pin every image tag (no `latest`). Bump tags deliberately and note it in `docs/decisions/`.
- Keep the `core` profile light: n8n, postgres, redis, mailpit, greenmail, minio(+init), mock-api. Heavier things go in
  `docs`, `ai`, `observability`, `queue` profiles.
- Every environment variable used in compose appears in `.env.example` with a dummy value and a comment.
- `docker compose -f docker/docker-compose.yml config -q` must pass after any edit (the post-write hook runs it).
- Seed data is generated by `seed/generate_seed.py` (deterministic). Edit the generator, regenerate, commit both.
- Never bake secrets into images or init scripts; the Postgres init reads credentials from the container env.
- Ports: 5678 n8n, 5432 postgres, 6379 redis, 8025/1025 mailpit, 3025/3143 greenmail, 9000/9001 minio, 8080 mock-api,
  8090 docgen, 11434 ollama, 6333 qdrant, 9010 whisper, 3001 metabase. Document any change in the README stack table.
