# Rules for workflows/

- Every folder follows the workflow-folder-contract skill exactly (README front-matter, workflow.json, assets/screenshot.png, test/).
- `workflow.json` is generated by an authoring script in `.claude/skills/n8n-workflow-json/authoring/` or exported
  from n8n via `scripts/export-workflows.sh`. Never hand-edit node ids or connections.
- Credentials only as `{id, name}` from the canonical `CREDS` table. No values, ever.
- `pinData` is always `{}`. Samples live in `test/`.
- Use only node types/versions from the allowlist in the n8n-workflow-json skill.
- Hostnames are compose service names (`postgres`, `mock-api`, `docgen`...). No `localhost` inside workflows except
  the n8n API credential.
- Synthetic data only: `@lab.local` emails, `.example.com` domains, fictional names.
- `status: shipped` requires the full acceptance checklist, including a live import + execution.
