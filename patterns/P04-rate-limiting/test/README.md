# P04 test fixtures

- `input.json` / `expected.json` - one gate call (`key=harness`, 5 per 10 s) and what the 1st and 6th call in the
  same window return; plus the report the harness prints.
- `harness.json` - generated by the authoring script: a manual-trigger workflow that fires 8 requests at
  `mock-api:8080/ratelimited` without the gate (expect 3 x 429), lets the server's window drain (11 s), then sends
  the same 8 requests one at a time through the gate at 2 per 10 s (expect 0 x 429, 3 throttles) and reports
  both counts. Why 2 and not 5: the server's window slides, the gate's is fixed - see the README's Trade-offs.

```bash
bash scripts/import-workflows.sh patterns/P04-rate-limiting --publish
docker compose cp patterns/P04-rate-limiting/test/harness.json n8n:/tmp/p04-harness.json
docker compose exec -T n8n n8n import:workflow --input=/tmp/p04-harness.json
python scripts/dev/run-workflow.py ALP04Harness0000          # ~30-45 s (it waits for the rate-limit windows)
docker compose exec -T redis redis-cli keys 'rl:harness:*'   # one key per 10 s window, TTL 11 s
```
