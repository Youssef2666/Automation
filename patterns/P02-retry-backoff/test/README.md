# P02 test fixtures

- `input.json` / `expected.json` - one call against `/flaky` (503 then 200).
- `harness.json` - generated by the authoring script: a manual-trigger workflow that calls P02 for four cases
  (flaky, always-down, 404, connection refused) and reports `{case, ok, status, attempts, terminal, retryable}`.

```bash
docker compose cp patterns/P02-retry-backoff/test/harness.json n8n:/tmp/p02-harness.json
docker compose exec -T n8n n8n import:workflow --input=/tmp/p02-harness.json
python scripts/dev/run-workflow.py ALP02Harness0000
```
