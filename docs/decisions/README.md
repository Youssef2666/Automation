# Architecture decision records

Short records of choices that deviate from [docs/PRD.md](../PRD.md) or that a reader would otherwise have to
reverse-engineer from the compose file. One file per decision, 15 lines max, never edited after acceptance
(write a new one that supersedes it).

## Template

Create `docs/decisions/NNNN-<kebab-title>.md` with the next free number (the `/adr` Claude Code command does this):

```markdown
# NNNN - Title

Date: YYYY-MM-DD
Status: accepted | superseded by NNNN

**Context**: two or three lines. What the PRD said, what we ran into (versions, env vars, service names).

**Decision**: one or two lines. What we do instead.

**Consequences**: what gets easier, what gets harder, what a reader must know.
```

Then add a row to the index above.
