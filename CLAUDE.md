# Automation Lab - Claude Code guide

Public showcase repo: a self-contained n8n 2.x stack (Docker Compose) plus a **coverage matrix** of workflows and
production patterns that all run offline against synthetic data. Source of truth for scope: `docs/PRD.md`.
Owner: Youssef Almerash. License MIT (n8n itself is fair-code and is not redistributed here).

## Hard rules (hooks enforce most of these; do not work around them)

1. **No secrets, ever.** Never write `.env`; only `.env.example` with dummy values. Workflow JSON references credentials
   as `{id, name}` only. Emails `@lab.local` / `@example.com`; no real people, clients, employers, or keys.
2. **Runs locally and free.** Core path of every item needs no cloud account, API key, or card. Optional external
   variants (Telegram, GitHub token) are documented as optional and never required.
3. **Contract or it does not ship.** A folder is `shipped` only after the acceptance checklist in
   `.claude/skills/workflow-folder-contract/SKILL.md` passes, including a live import + execution.
4. **n8n 2.37.10 pinned.** Node types/versions only from the allowlist in `.claude/skills/n8n-workflow-json/SKILL.md`.
   Execute Command stays disabled; no Python Code nodes; no `$env` in workflows.
5. **Generate, do not hand-write JSON.** Workflows come from authoring scripts (`.claude/skills/n8n-workflow-json/authoring/`)
   using `n8n_builder.py`, or from `scripts/export-workflows.sh`. Never hand-edit ids/connections.
6. **Synthetic data only**, generated by `seed/generate_seed.py`. Edit the generator, not the SQL.
7. **Nothing destructive without asking**: no force pushes, no volume wipes, no history rewrites, no `data/` deletes.

## Daily commands

```bash
docker compose --profile core up -d && bash scripts/setup.sh     # stack + owner + credentials + import + publish
python scripts/validate.py [folder]                              # contract + secrets (CI gate; Stop hook runs it too)
python scripts/build-matrix.py                                   # regenerate README matrix
python .claude/skills/n8n-workflow-json/authoring/<ID>_<slug>.py # regenerate one workflow.json
python scripts/render-preview.py <folder>                        # preview screenshot (stack down)
python scripts/dev/canvas-screenshots.py [folder]                # real canvas capture, headless (stack up)
bash scripts/import-workflows.sh <folder> [--publish]            # push to n8n
bash scripts/export-workflows.sh                                 # pull from n8n (credentials stripped)
```

Slash commands: `/new-workflow`, `/new-pattern`, `/validate`, `/build-matrix`, `/stack`, `/import`, `/export`,
`/ship-check`, `/milestone`, `/screenshot`, `/secret-scan`, `/smoke`, `/adr`.
Agents: `workflow-builder`, `pattern-author`, `workflow-reviewer`, `docs-writer`, `stack-engineer`, `qa-runner`.
Hooks (`.claude/hooks/`): secrets guard on writes, Bash guard on destructive commands, post-write JSON/README checks,
session banner, and a Stop hook that blocks finishing once while `scripts/validate.py` reports errors (self-correction).

## How work flows

1. Pick the next item from `/milestone` (patterns before the workflows that use them: P01 -> T01 -> ...).
2. Build it with the `workflow-builder` (or `pattern-author`) agent; several independent items can run in parallel.
3. Review with `workflow-reviewer`; verify live with `qa-runner` (`/smoke`, `/ship-check <ID>`).
4. Keep docs honest: any deviation from the PRD gets an ADR (`/adr`) and a "Notes & trade-offs" line.
5. Commit in small, conventional commits (`feat(T03): ...`, `docs: ...`, `ci: ...`); CI must stay green on `main`.

## Environment notes

- Windows host, Git Bash for `Bash`, Python 3.13 as `python` (not `python3`), Docker Desktop (daemon may be off).
- The compose file path is set via `COMPOSE_FILE=docker/docker-compose.yml` in `.claude/settings.json`; run compose from the repo root.
- Long files: use the Write tool (shell command length is limited on Windows).
- Docs/knowledge: n8n docs moved to `https://docs.n8n.io/<section>.md`; `docker compose config -q` works without the daemon.
