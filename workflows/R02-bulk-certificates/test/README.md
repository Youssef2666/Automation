# R02 test inputs

`certificates-sample.csv` - the 12-row course-completion list (same as `seed/files/certificates.csv`, generated by
`seed/generate_seed.py`; synthetic names, `@lab.local` e-mails). Columns: `full_name,email,course,hours,completed_on,instructor`.
Default run reads it from the seed mount; to use an edited copy put it in `data/inbox/` and change Config.file.
